# 分析口径

当前项目的观察重点是 regional sample support。来源信息、观测记录与分析输出分别保存；报告保留生成时使用的来源标识，便于研究人员回看数据范围。输入观测的数值含义由调用方提供，项目不将报道计数解释为受众态度或传播因果。

## 区域分析的样本支撑口径

`regional_breakdown` 与 `regional_trends` 在输出趋势和排名时，同时给出有效观察数量、来源构成与覆盖缺口，使用规则如下：

- **有效观察**：仅统计在来源目录中在册、且未暂停来源的观察。已暂停来源的观察与无法归属来源的观察不参与指标，但分别列入覆盖缺口，可追溯到具体观察与来源标识。
- **地区归属以来源目录为准**：观察按其来源在目录中的现行地区映射分组，观察记录自带的地区字段不参与分组；两者不一致时记入 `stale_region_observations`，避免归属修正前的历史字段污染现行统计。
- **缺失地区不压成零**：在册有效来源存在、但周期内没有观察的地区以 `no-data` 形态保留（`value` 与 `share_of_total` 为 `null`、无排名），并进入 `regions_without_observations`。零值与“没有数据”在输出中严格区分。
- **小样本与来源集中**：有效观察少于 5 条的地区标记为 `thin` 并附 `small-sample` 警告；单一来源占地区观察值达到 60% 时附 `dominant-source` 警告（样本充足时状态为 `concentrated`）。排名仅按观察总值排序，小样本地区不会因单条高值被暗示为代表性充分。
- **覆盖缺口**：每个地区列出在册但本周期无观察的来源（`missing_source_ids`），全局缺口另含无观察地区、暂停来源及其观察、无法归属的观察。
- **解读边界**：方法说明固定提示，报道情绪与计数是媒体层面的观察，不能转述为当地公众态度，也不构成传播效果的因果结论。

## 来源变更的一致性

归属修正、暂停与恢复通过 `SourceCatalog.upsert / suspend / resume` 完成。分析每次都从目录读取现行映射与状态，因此来源变更后重跑分析，相关地区的指标、来源构成与支撑说明会一起更新；对未知来源执行暂停或恢复会抛出 `KeyError`，不会静默忽略。

## 已发布分析的回看

`create_regional_report` 生成不可变快照，固化发布时刻的：

- 区域映射（`region_mapping`，来源 -> 地区）；
- 来源范围（`source_scope`，含在用与暂停来源清单及其属性）；
- 完整统计结果（`regional_results`，含排名、样本支撑与覆盖缺口）；
- 方法说明与解读边界。

快照可经 `report_to_json / report_from_json` 序列化留存。发布之后对目录的任何修正都不会改写历史报告，回看时呈现的始终是当时的映射、来源范围与统计结果。
